# Welcome to BIPES!

**BIPES: Block based Integrated Platform for Embedded Systems** allows text and block based programming for several types of embedded systems and Internet of Things modules using MicroPython, CircuitPython, Python or Snek.

You can connect, program, debug and monitor several types of boards using network, USB or Bluetooth. Please check the list of [compatible boards](https://bipes.net.br/wp/boards/). Compatible boards include STM32, ESP32, ESP8266, Raspberry Pi Pico and even Arduino.

**BIPES** is fully [open source](https://bipes.net.br/wp/development/) and based on HTML and JavaScript, so no software install or configuration is needed and you can use it offline.

If you need help, we now have a [discussion forum](https://github.com/BIPES/BIPES/discussions) where we also post [new features and announcements about BIPES](https://github.com/BIPES/BIPES/discussions/categories/announcements). Feel free to use it, and use the forum to leave feedback and suggestions for BIPES.

Now you can easily load MicroPython on your ESP32 or ESP8266 to use with BIPES: [ESP Web Tools](https://bipes.net.br/flash/esp-web-tools/)

Checkout the BIPES book at [https://bipes.net.br/wp/book-livro/](https://bipes.net.br/wp/book-livro/)
