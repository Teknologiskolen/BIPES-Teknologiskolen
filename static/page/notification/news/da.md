# Velkommen til BIPES!

**BIPES: Blokbaseret Integreret Platform for Indlejrede Systemer** tillader tekst- og blokbaseret programmering for flere typer indlejrede systemer og Internet of Things-moduler ved hjaelp af MicroPython, CircuitPython, Python eller Snek.

Du kan oprette forbindelse, programmere, fejlfinde og overvaage flere typer af boards via netvaerk, USB eller Bluetooth. Se en liste over [kompatible boards](https://bipes.net.br/wp/boards/). Kompatible boards inkluderer STM32, ESP32, ESP8266, Raspberry Pi Pico og endda Arduino.

**BIPES** er fuldt [open source](https://bipes.net.br/wp/development/) og baseret pa HTML og JavaScript, sa der ikke kraeves softwareinstallation eller konfiguration, og du kan bruge det offline.

Hvis du har brug for hjaelp, har vi nu et [diskussionsforum](https://github.com/BIPES/BIPES/discussions), hvor vi ogsa poster [nye funktioner og meddelelser om BIPES](https://github.com/BIPES/BIPES/discussions/categories/announcements). Brug det endelig, og del gerne feedback og forslag til BIPES.

Nu kan du nemt indlaese MicroPython pa din ESP32 eller ESP8266 til brug med BIPES: [ESP Web Tools](https://bipes.net.br/flash/esp-web-tools/)

Se BIPES-bogen pa [https://bipes.net.br/wp/book-livro/](https://bipes.net.br/wp/book-livro/)

Tak fra BIPES-teamet!
